# 🇫🇷 Glory of France Clicker

Un jeu de type **clicker** inspiré de Cookie Clicker, centré sur l'histoire et la culture française.

## 🎮 Comment jouer ?
- Cliquez sur le **Drapeau Français** pour gagner des **Points de Gloire**.
- Achetez des **éléments historiques** (Coq Gaulois, Vercingétorix, etc.) pour générer des points automatiquement.
- Déblocquez des **améliorations** pour booster votre production.
